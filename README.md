# 🎯 Guessing Number Game

A simple **Guessing Number Game** built using **HTML, CSS, and JavaScript**.

The computer randomly selects a number, and the player has to guess the correct number. After each guess, the game gives a hint whether the guessed number is **too high** or **too low**.

## 🚀 Features

* 🎲 Random number generation
* 🔢 User input for guessing
* 💡 Hints for high/low guesses
* 🏆 Displays the result when the correct number is guessed
* 🔄 Simple and beginner-friendly interface

## 🛠️ Technologies Used

* **HTML** – Structure of the game
* **CSS** – Styling and layout
* **JavaScript** – Game logic and random number generation

## 🎮 How to Play

1. Open the game in your browser.
2. Enter a number in the input field.
3. Click the **Guess** button.
4. The game will tell you whether your guess is:

   * Too high
   * Too low
   * Correct
5. Keep guessing until you find the correct number.
